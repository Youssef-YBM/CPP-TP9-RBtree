TP9 - Arbre rouge-noir et comparaison avec std::map
==================================================

Depuis PowerShell :

Set-Location 'C:\Users\youss\OneDrive\Documents\ILISI 2\2026 Cpp Avance et Virtualisation\TPs\TP9'
g++ --version
g++ -std=c++17 -m64 -O2 -Wall -Wextra -Wpedantic rbtree_benchmark.cpp -o rbtree_benchmark.exe
.\rbtree_benchmark.exe

Le programme affiche un menu :

1. Inserer une paire cle/valeur
2. Rechercher une cle
3. Supprimer une cle
4. Afficher l'arbre en ordre croissant
5. Valider les invariants rouge-noir
6. Comparer les operations a std::map
7. Lancer les tests automatiques
0. Quitter

Choisir 6, puis entrer N (de 1 a 2 000 000). Le programme genere N cles
aleatoires distinctes, utilise les memes cles et valeurs pour RBTree et
std::map, puis compare insertion, recherche de toutes les cles et suppression.
Chaque operation est repetee 5 fois, apres une chauffe; l'ordre de mesure des
deux structures alterne. Les temps affiches sont les medianes en ns/operation
et le rapport est std::map/RBTree. Les recherches alimentent un checksum.

Les mesures des quatre tailles ont ete executees sur le MSI et sont deja
enregistrees dans resultats_benchmark.csv. Le rapport rapport_rbtree.tex lit
ce fichier et affiche les trois graphes. Pour regenerer le PDF depuis ce
dossier (avec une distribution LaTeX installee) :

pdflatex -interaction=nonstopmode -halt-on-error rapport_rbtree.tex

Pour actualiser les mesures, relancer l'option 6 pour chaque taille et
remplacer les valeurs correspondantes dans resultats_benchmark.csv.

Pour lancer uniquement les tests automatiques sans ouvrir le menu :

.\rbtree_benchmark.exe --test

Le benchmark est mono-thread CPU. Pour des mesures comparables, travailler
sur secteur, garder le meme mode d'alimentation et fermer les applications en
arriere-plan. Les resultats dependent de la machine; aucun temps du rapport
n'est reutilise.
